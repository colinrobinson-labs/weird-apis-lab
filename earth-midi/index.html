Where AI is (and isn't)

LabelWhat it means here
Raw dataNumbers straight from the scientific source, unchanged.
AlgorithmicFixed formulas (listed on each channel) turn data into notes and controllers. The same input always gives the same output. This is the kind of mapping musicians have done with synths since the 1970s.
AI-assistedNot used anywhere in this version. If it's ever added (for captions, for example), it will be labelled, and it will never generate the audio.

Use it in your DAW

Open this page in Chrome or Edge, choose a MIDI output, then route it into Ableton, Logic or any synth. On a Mac, enable the IAC Driver bus in Audio MIDI Setup. On Windows, use loopMIDI. The built-in synth is just a preview. The point is what you make with the signal.

Channels: 1 = quakes (notes), 2 = sun (CC 1–4), 3 = ocean (notes + CC 5).

Sources

USGS earthquake feeds · NOAA Space Weather Prediction Center · Open-Meteo Marine (CC BY 4.0). Data is refreshed every 60 seconds. If a source can't be reached, the channel says so and plays recorded demo data, labelled demo.

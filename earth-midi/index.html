    Where AI is (and isn't)

    LayerWhat it is
    DataRaw USGS, NOAA SWPC, GOES, Open-Meteo. Values are never smoothed, invented or predicted.
    MappingAlgorithmic fixed formulas, shown on each card. The same data always gives the same notes.
    SoundAlgorithmic Web Audio synthesis: FM bells, saw pads, filtered noise, convolution reverb. No samples.
    AINot used anywhere. No generated audio, no ML models.

    Use it in your DAW

    • Mac: Audio MIDI Setup → MIDI Studio → IAC Driver → tick “Device is online”. Pick “IAC Driver Bus 1” above, then arm a MIDI track in Ableton, Logic or Bitwig.
    • Windows: install loopMIDI, create a port, pick it above.
    • Use Chrome or Edge, which support Web MIDI. Channels 1–4 are as labelled on each card.

    Accuracy

    Replay mode compresses the last 24 hours, keeping every quake in its real order and real relative spacing. The clock shows the real UTC time being played. Live mode plays new quakes within about a minute of USGS publishing them. Solar wind is the DSCOVR/ACE feed at the L1 point, roughly 30–60 minutes before it reaches Earth. If any source fails, that card says demo and nothing is passed off as live.

# weird-apis-lab

Prototypes built on unusual public APIs. Live at https://colinrobinson-labs.github.io/weird-apis-lab/

| Folder | What it is |
|---|---|
| `trip-health/` | Salu Atlas, a per-destination health risk check with levels, actions and reliability grades |
| `earth-midi/` | Earth MIDI, planetary sensor data turned into a Web MIDI output (raw and algorithmic, no AI) |
| `zombie-facts/` | Zombie Facts, retracted papers still cited on Wikipedia |
| `gear-tracker/` | GSA Auctions event gear deal digest posted to Slack (Python, see its README) |

Each app is a single static HTML file deployed by `.github/workflows/pages.yml`.
